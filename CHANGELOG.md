# Changelog

All notable changes to DimiPress Detour are documented here.

## 1.0.1 — 2026-09-23

- Set Aleksa Dimitrijević as the plugin author and add the author profile URL.
- Add the plugin page URL.
- Refine the plugin description and update documentation metadata.

## 1.0.0 — 2026-09-23

- Add an admin settings page to select a published destination page.
- Add an option to allow the selected page and its descendant pages.
- Always grant administrators full site access and allow other WordPress roles to be selected for full access.
- Redirect public front-end GET and HEAD requests with a temporary HTTP 302.
- Exempt WordPress administration and integration requests.
- Include English installation, contribution, security, and license documentation.
