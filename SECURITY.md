# Security Policy

DimiPress Detour is maintained by [Aleksa Dimitrijević](https://dimitrium.org/en/dimipedia/aleksa-dimitrijevic). Project page: <https://dimitrium.org/en/dimipress/detour>.

## Supported versions

Security fixes are provided for the latest released version of DimiPress Detour. Update to the latest version before reporting an issue.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Contact the site or repository maintainers privately with a description, affected version, steps to reproduce, and potential impact. Allow maintainers reasonable time to investigate and prepare a fix before public disclosure.

Do not include live credentials, private visitor data, or unrelated production data in a report.
